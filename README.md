# PDF 容量削減ツール

`origin` フォルダに入れた PDF のデータ容量を削減し、`reduced` フォルダに出力します。

## 必要なもの

- Windows
- Python 3（https://www.python.org/ ）
- PyMuPDF（未インストールの場合は初回実行時に自動でインストールされます）

## 使い方

1. `origin` フォルダに圧縮したい PDF を入れる（サブフォルダも可）
2. `reduce.bat` をダブルクリック
3. `reduced` フォルダに同じファイル名・フォルダ構成で出力される

実行すると、ファイルごとの圧縮前後のサイズと削減率が表示されます。

## 圧縮レベル

コマンドプロンプトから引数を付けて実行すると、圧縮の強さを変更できます。

```
reduce.bat low      画質優先（150dpi・JPEG 品質 85）
reduce.bat          標準    （120dpi・JPEG 品質 75）※ medium と同じ
reduce.bat high     容量優先（96dpi・JPEG 品質 60）
```

各レベルの数値は `reduce_pdf.py` の `PRESETS` で変更できます。

## 処理内容

- 解像度の高い画像を縮小し、JPEG で再圧縮する
- フォントを使用している文字だけに絞り込む（サブセット化）
- 不要なオブジェクトやサムネイルを削除し、ストリームを圧縮する
- 圧縮後のほうが大きくなった場合は、元のファイルをそのままコピーする

## 注意

- 容量が大きく減るのは、スキャンした PDF や画像の多い PDF です。文字だけの PDF はあまり減りません。
- 元の PDF は変更されません。`reduced` にある同名のファイルは上書きされます。
- 画像を再圧縮するため、画質は多少落ちます。気になる場合は `low` を使ってください。

## ファイル構成

```
pdf_reduce/
├── reduce.bat      実行用バッチファイル
├── reduce_pdf.py   圧縮処理の本体
├── origin/         入力 PDF を置くフォルダ
└── reduced/        圧縮後の PDF の出力先
```
